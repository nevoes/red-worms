# המרכז לתולעי מיחזור – כל תולעת מלכה

האתר של המרכז לתולעי מיחזור (שרית ואשד נבו). אתר סטטי בעברית, מתארח ב-GitHub Pages.

כתובת זמנית: https://nevoes.github.io/red-worms/

## מבנה

| עמוד | קובץ |
|---|---|
| בית | `index.html` |
| היכרות עם התולעים האדומות (כולל איך מתחילים, קיץ, חבית שתילה, מעבר דירה, משלוח, מחשבון) | `worms.html` |
| הומוס (שיטות הפרדה, קציר, סינון, תה הומוס) | `humus.html` |
| שאלות ומילון המגדל | `faq.html` |
| חנות, משלוחים, טופס הזמנה ופנייה, דפי מידע להורדה | `shop.html` |

## עריכה

- את התוכן עורכים בקבצים שבתיקייה `src/` (רק גוף העמוד).
- הכותרת העליונה, התפריט והכותרת התחתונה משותפים לכל העמודים, ונמצאים ב-`tools/build.py`.
- אחרי עריכה מריצים `python3 tools/build.py`, והעמודים בתיקייה הראשית נבנים מחדש.
- עיצוב: `assets/style.css`. פעולות (תפריט, מחשבון, טופס): `assets/site.js`.

## לוגו

הלוגו נמצא בקובץ אחד: `assets/logo.svg` (סמל זמני – תולעת עם כתר). כדי להחליף לוגו מחליפים את הקובץ הזה, וההחלפה מופיעה בכל האתר.

## טופס ההזמנה

הטופס ב-`shop.html` שולח את התשובות ישירות לטופס הגוגל הקיים ("יצירת קשר, הזמנה ותשלום"), כך שההזמנות ממשיכות להגיע לאותו גיליון תשובות כמו קודם. המיפוי לשדות נמצא בראש קטע הטופס ב-`assets/site.js` (המשתנה `E`). אם משנים שאלות בטופס הגוגל, צריך לעדכן גם את המיפוי.

## חיבור הדומיין red-worms.net

1. ב-Settings → Pages של הריפו, בשדה Custom domain, כותבים `www.red-worms.net` (נוצר קובץ `CNAME`).
2. אצל רשם הדומיין: רשומת CNAME ל-`www` שמצביעה על `nevoes.github.io`, וארבע רשומות A לדומיין הראשי:
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
3. אחרי שהדומיין עובד, מסמנים Enforce HTTPS.

## ארכיון האתר הישן

ה-Action בשם **Archive old site images** (בלשונית Actions, הפעלה ידנית) מוריד את כל התמונות מהאתר הישן ב-Google Sites לתיקייה `archive/old-site-images/`, כולל הלוגו הישן.
